## 🚀 快速开始

> 推荐 Chrome / Edge / Firefox 最新版。

### 方式一：直接打开（最简单）

双击项目根目录下的 [`index.html`](index.html)，即可进入训练面板。

### 方式二：本地起一个静态服务器（推荐，避免个别浏览器对本地 file:// 的策略限制）

在项目目录下任选其一：

```bash
# 有 Python 的话
python -m http.server 8080

# 有 Node.js 的话
npx serve -l 8080 .
```

然后浏览器访问 `http://localhost:8080`。

## 🎮 操作面板

顶部按钮：

- ▶ **训练**：按当前超参数开始 Double DQN 学习
- 👁 **演示**：用当前网络纯贪心策略跑（不训练，ε=0）
- ⏸ **暂停**：冻结状态，可继续 / 保存
- ⟳ **重置**：清空网络、经验池、统计、曲线
- ✋ **人工采集**：空格手动玩，样本直接写入经验池
- 💾 **保存**：写入 localStorage + 下载 `flappy_model.json` 覆盖当前
- 📂 **载入**：从 localStorage 读回上次保存的模型
- 📤 **备份**：导出带时间戳的 JSON，留档对比不同训练阶段效果
- 📥 **导入**：导入任意备份 JSON

滑块：
- **训练速度**（1x~20x）：训练模式每帧跑多少步，调高性能直接起飞
- **演示速度**（1x~6x）：演示/测试模式的倍速
- **渲染**：关掉后走 `setTimeout` 纯后台训练，帧率最高
- **调试**：画状态向量、管道间隙辅助线

## 🧠 算法细节

### 状态向量（10 维，归一化到 [0,1]）

| 索引 | 含义 |
|---|---|
| s0 | 鸟 Y 坐标（画布高度归一化）|
| s1 | 鸟垂直速度 |
| s2 | 到下一根管道的水平距离 |
| s3 | 下管道 上管壁 Y / 间隙上沿 |
| s4 | 下管道 下管壁 Y / 间隙下沿 |
| s5 | 下管道 间隙中心 Y |
| s6 | 下管道 间隙中心 相对于 鸟Y 的偏移 |
| s7 | **第二根**管道 上管壁 Y（前瞻）|
| s8 | **第二根**管道 下管壁 Y（前瞻）|
| s9 | **第二根**管道 间隙中心 Y（前瞻）|

> 加入 s7~s9 后，面对「下一根低、再下一根突然超高」的突变地形，网络能提前做姿态准备，比只用 7 维的收敛稳定很多。

### 动作

- `0`：不拍翅（重力下落）
- `1`：拍翅（向上瞬时速度，受最大下落速度限制）

### Double DQN 结构

```
输入 (10) → 隐藏1 (128, ReLU) → 隐藏2 (128, ReLU) → 输出 (2, 线性)
```

- 经验回放容量：`20000`
- 批量：默认 `64`
- 目标网络更新：每 `500` 训练步把在线网络权重拷贝到目标网络
- ε 衰减：每局死亡 ε 乘 `0.995`，最低 `0.01`
- γ 折扣：默认 `0.95`
- 优化器：Vanilla SGD + MSE loss（自实现，纯 JS）

### 奖励塑形（实时可调）

```
r_total = r_survive           （每帧 +0.001，让它先学会"别死"）
        + Σr_gap_reward       （越靠近间隙中心越大，系数默认 1e-6）
        + r_gap_penalty_below （在间隙下方罚 -0.05/帧，防贴底）
        + r_gap_penalty_above （在间隙上方罚 -0.05/帧，防拍翅过猛）
        + r_death              （撞墙 -1，终结信号）
```

直接在右侧「奖励塑形 · 间隙引导」改数值 → **应用奖励参数**，立刻生效。

## 🔧 调参小抄

| 现象 | 建议调整 |
|---|---|
| 一直撞顶 | 加大「上方罚/帧」或减小「拍翅瞬时速度」(game.js 内) |
| 一直贴地死 | 加大「下方罚/帧」或加大「存活/帧」 |
| 死了不会穿过管道 | 减小 `ε` 初始 / 降低 γ 让它更关注下一秒 |
| 分数突破不了某根管道 | 打开「人工采集」亲手示范 20~50 局再继续训练 |
| Loss 一直不下降 | 把学习率 α 减半（默认 0.0005，试 0.0001）|
| 曲线不更新但局数在涨 | 看下图「本局未结束」条 → 大概率是本局还没死 |

## 🛠 常见问题

**Q：打开后画面是黑的/报错？**
A：推荐用 `python -m http.server 8080` 起本地服务，不要直接 `file://` 打开。

**Q：重置后模型没了？**
A：重置只清内存和 localStorage，你点过「备份」的时间戳 JSON 文件都在下载目录里，可以用「导入」恢复。

**Q：能把模型用到别的 Flappy 项目吗？**
A：可以，`agent.serialize()` 导出的 JSON 里有权重、超参、状态维度，格式见 `js/agent.js` 末尾的 serialize / deserialize。

**Q：训练多久能跑 100 分？**
A：默认参数 + 渲染关闭 + 20x 速度，通常 3000~8000 局能稳定过 50 分，偶尔能到几百。经验池越满、人工采集越对，收敛越快。
